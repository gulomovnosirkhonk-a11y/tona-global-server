DO‘STLAR BILAN YAQINROQ

Sizning davrangiz.
Har bir qurilmada.

Telefoningiz yoki kompyuteringizdan TONA’ni alohida ilova oynasida oching.

Qurilmangiz uchun quyidagi yo‘lni tanlang.

01 / TELEFON

Android

Chrome’da saytni oching. Menyudan Ilovani o‘rnatish / Install app yoki Bosh ekranga qo‘shish ni tanlang.

02 / TELEFON

iPhone va iPad

Safari’da Ulashish → Bosh ekranga qo‘shish ni bosing. Ko‘rsatilsa, Open as Web App ni yoqing.

03 / KOMPYUTER

Windows

Chrome yoki Edge’da manzil qatoridagi o‘rnatish belgisini yoki brauzer menyusidagi Ilovalar → O‘rnatish ni tanlang.

04 / KOMPYUTER

Mac

Mos Safari versiyasida File → Add to Dock ni tanlang. Chrome yoki Edge’da ham saytni ilova sifatida o‘rnatishingiz mumkin.

Bu saytdan o‘rnatiladigan veb-ilova. App Store / Google Play paketi yoki EXE / DMG yuklamasi emas. O‘rnatish imkoniyati brauzer va tizim versiyasiga bog‘liq.

Suhbat va media uchun internet kerak. Fon qo‘ng‘iroqlari va push bildirishnomalari hali qo‘shilmagan.
